# Decision making across learning phases (DDM vs. Wang model)

How do decision parameters change as people learn a task? I split behavioural data from a decision-making task into early, middle and late learning phases and fitted two models to each phase:

- **Drift Diffusion Model:** drift rate, decision boundary, non-decision time
- **Wang model:** threshold and noise

The parameters shift systematically between phases, which says something about how learning changes the speed and consistency of decisions.
